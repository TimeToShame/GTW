## Протестированные функции

### 1. Профиль пользователя ✅
- **GET /api/profile** - получение профиля пользователя
  - Статус: 200 OK
  - Возвращает: user_id, username, first_name, birthdate, interests, created_at

- **PUT /api/profile** - обновление профиля
  - Статус: 200 OK
  - Обновляет: birthdate, interests
  - Проверено: данные корректно сохраняются в БД

### 2. Wishlist ✅
- **POST /api/wishlist** - добавление товара в wishlist
  - Статус: 200 OK
  - Добавлено 3 тестовых товара
  - Возвращает: item_id для каждого товара

- **GET /api/wishlist** - получение wishlist
  - Статус: 200 OK
  - Возвращает массив товаров с полями: id, title, description, price, url, image_url, created_at

- **PUT /api/wishlist** - обновление товара
  - Статус: 200 OK
  - Обновлены: price и description первого товара

- **DELETE /api/wishlist/{item_id}** - удаление товара
  - Статус: 200 OK
  - Товар успешно удалён из БД
